# rag-v1-dev-seen

三个已见合成整合任务：正常事实+监护依据、过期事实+资质依据、知识无结果。不是holdout。每次生成实际JSON派生事实文件，仅改变租户和版本标记，报告保存原/派生摘要；知识摄取到同一独立租户，避免污染演示空间。

默认`evaluate_rag.py --output <新路径>`使用scripted协议替身，但知识编码与PG查询是真实的；显式--mode deepseek才使用共享预占，工作包P2-WP04。每任务最多3请求/4工具动作，无重试，包10/新授权累计100。查看已有真实报告无需再次请求。

自动评分核对三工具观察、完整事实值/outcome/reason、被选择的引用是否属于支持文档及原文；无结果必须有明确知识unknown观察与完成候选，不用空集合假通过。knowledge_answer_supported仅指所选引用，support_scope明确不覆盖全部自由摘要主张；summary_semantics仍要求人工复核。

WP04的真实第二例保留了摘要额外主张未显式引用相应次要片段的问题。引用合法不能当成全部主张得到支持；新增评分器边界修复后对归档重新评分，未重跑模型或改写原始输出。
