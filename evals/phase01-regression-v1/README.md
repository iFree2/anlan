# P1 冻结工程回归 v1

这是8个开发者已见的合成工作流案例，验证材料循环/版本/权限/幂等/故障降级，不是模型语义基准，也不是独立holdout。`inject_model_timeout` 是明确标注的故障注入，普通案例使用OfflineAnalyzer；全部案例执行真实服务入口和LangGraph。

`manifest.json` 冻结cases、WP03历史预测、对应dev标签的规范化JSON摘要。摘要按UTF-8、排序键、无多余空白生成，兼容Git行尾转换。执行前验证全部文件；内容变更应创建新版本，不能改v1期望迁就失败。该摘要用于漂移检测，非供应方签名或防篡改系统。

每个步骤核对状态、revision、问题字段、分析次数和全部材料字段；拒绝时核对前后状态不变。失败案例仍保存结果，runner退出码为1；文件/摘要无效退出码为2；输出文件不可覆盖。

历史三例仅重新计算问题集合评分：来源为WP03保存预测，标签是当时已见dev。它不调用模型、不执行历史工具/告警、不构成全轨迹回放，不证明当前模型行为。历史用量与本次0请求分列。

```powershell
uv run python evals/phase_gate.py --output .runtime/p1-regression.json
```

阶段工程Gate还需结合真实PostgreSQL集成、完整跨进程演示与WP03原始有限模型证据；不能仅凭8例通过就宣称生产安全、模型质量或本人掌握达标。
