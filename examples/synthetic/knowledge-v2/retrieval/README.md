# K3a 合成离线结构检索

TXT 场景在测试中调用 K2a `parse_txt`，输入真实合成 UTF-8 bytes，保留原字节
hash 和行号；不是从网络获取的企业资料。默认草稿没有发布清单，不能检索。
通过用例显式注入的审核/发布/ACL 均是测试宿主夹具，不是真人审核记录。

`table-ir.json` 是手工构造的矩形 XLSX 结构 IR，没有对应真实工作簿。
source/config hash 为格式合法的占位值，不能证明原文件存在或来源真实性。
地址 B3 仅从审核结构范围 A1:B4 和两行表头推导，标为
`derived_from_reviewed_ir`；字符串包含不证明真实物理地址。

已见回归覆盖：精确编号、BM25/RRF、向量确定性排名替身、每路候选前治理、
撤回/收权/回滚、父投影缺项、IR/投影篡改、表格 Decimal 筛选、200 行扫描、
32 节点/64KiB/5 秒预算、取消与最终序列化越时。单元格结果必须和源表原文、
表头、单位、脚注一起保留；裁剪不产生孤立数值。

没有真实 embedding、搜索平台、检索质量金标或语义正确率结论，不装配旧工具。
测试入口为 `tests/test_knowledge_v2_retrieval*.py`。
