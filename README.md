# 安澜（ANLAN）Agent 智能体平台 — 项目素材库

> 面向 **安全生产** 领域的 Agent 智能体平台设计与实践。
> 设计范式：**行业场景为原点痛点（需求）→ Agent 编排（主体）→ 业务工具层（底座）→ Harness（质量保障）→ 数据回流（自进化）**。

---

## 1. 业务介绍

### 行业背景
安全生产是强合规、强责任追溯的领域：判级有法定标准、作业有许可流程、应急有黄金时间。Agent 的价值不是「聊天」，而是把**合规闭环型业务**智能化——这也是行业壁垒所在。

### 核心业务（三个命脉场景）

| 场景 | 解决什么问题 | 业务本质 |
|---|---|---|
| **S1 隐患排查治理闭环** | 一线口语化上报 → AI 结构化 → 判级（规则+LLM 双通道）→ 整改 → 复查证据链 → 销号 | 对已存在缺陷做**分类判定**（判级一致性是红线） |
| **S2 高风险作业审批** | 动火/有限空间等八大作业票：AI 预审 → 逐级审批 → 开工核验（传感器联动）→ 过程监控 → 完工销票 | 对将发生的高风险行为做**事前许可**（流程与真实性是红线） |
| **S3 应急指挥处置** | 事件识别 → 秒级先期处置（联动广播/门禁/视频）→ 决策增强 → 指挥/现场协同 → 复盘 | 对突发事件的**时效处置**（确定性优先是红线） |

### 平台设计理念（一句话）
**Agent 是主体，业务系统是工具底座；AI 只出建议+证据链，终裁权在人；规则兜底、LLM 增强；确定性优先、智能增强。**

## 2. 技术栈

### 分层技术栈总览

| 层 | 技术选型 | 说明 |
|---|---|---|
| 应用层 | 三个行业 Agent（判级/审批/应急 Agent 群） | 入口：Web / App / 语音 / 拍照 / 指挥大屏 |
| 编排层 | **LangGraph / LangChain**（Python 为主） | 确定性流程 = 预定义 StateGraph；开放场景 = ReAct 动态图；checkpoint 长时交互 |
| 行业治理扩展（自研） | 副作用分级 / 多租户 ACL / 调用审计 / 契约测试 / Skill 生命周期 / 逐步骤埋点 | 框架有机制、没治理——自研收敛到这里 |
| 能力封装 | **Skill 工程**（判级/预审/预案匹配/证据链）+ **MCP 工具注册中心** | Skill 管业务能力（可评测可治理），MCP 管系统接入 |
| 业务工具层（Java） | Spring + Drools 规则引擎 + 自研状态机（事件溯源）+ 联动执行网关 | 业务闭环权威源，Agent 不可绕过 |
| 知识数据 | 条款/规程/预案知识库（版本化+引用校验）｜Milvus + ES + Neo4j（GraphRAG）+ bge-m3/Rerank | 混合检索 + 引用溯源 |
| 模型服务 | **vLLM** 私有化推理 ｜ Qwen-32B（判级）· 7B（轻任务）· 1.5B（边缘）｜ VLM（拍照识隐患）· bge Embedding | AWQ 量化 + 昇腾/寒武纪信创适配 |
| 记忆 | Redis（会话）+ PG + Milvus（长期/画像）+ 事件溯源（状态记忆） | 状态以业务工具层为准 |
| 数据管道 | OTel → Kafka → Flink（实时）→ Iceberg → Doris | 实时 + 批式双链路 |
| Harness | 自研三层评测：L0 工具契约 / L1 Skill 评测 / L2 Agent 端到端 | 轨迹 Replay + 演练注入 + 一致性门禁 + 发布门禁 |
| LLMOps | 自研（对标 Langfuse/LangSmith） | Trace → 指标大盘 → Badcase 复现 |
| 部署 | 私有化 + 信创：A800 / 昇腾 910B GPU 集群 + 每园区边缘节点（断网 T0 可用） | 数据不出园 |

### 核心工程原则
1. **机制用主流，治理自研**：LangGraph/LangChain 管编排与工具机制，行业治理层（副作用分级/审计/Skill 生命周期）自研；
2. **规则兜底，LLM 增强**：事实性校验（资质/条款/时间）走规则层权威数据源，LLM 只配碰开放文本；
3. **确定性优先**：应急 T0 联动、判级仲裁等责任动作不依赖 LLM 自由发挥；
4. **Harness 是第二条生产线**：每次变更（Prompt/Skill/模型/规则）自动回归，不达标禁止发布。
