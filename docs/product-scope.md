# 安澜 2.0：产品范围

面向企业安全管理人员的**高风险作业全周期安全协同 Agent**。半年约 26 周，每周 15—20 小时；以动火作业做深，通过真实工程实践形成可解释、可修改、可排错、有实验数据的求职项目。材料辅助核查只是入口。

业务主线：作业申请与材料理解 → 缺项/歧义追问 → 当前事实与制度查询 → 风险辅助分析 → 安全管理人员复核 → 作业中感知事件协同 → 条件变更与重新核查 → 反馈复盘 → Badcase、记忆和智能资产沉淀。

| 相连场景 | 用户得到什么 | 主要边界 |
|---|---|---|
| 准备与预审 | 多轮材料补充、可恢复的任务状态 | 申请人等用测试身份模拟；不建完整门户 |
| 依据与风险 | 有来源、时效、冲突和未知项的辅助建议 | 当前事实由工具查询，示例知识不能充当真实合规依据 |
| 作业中协同 | 结构化事件与当前作业关联、依据与待人工确认建议 | 原始报警、阈值、联锁和实时控制独立运行 |
| 复盘改进 | 轨迹到反馈、Badcase、实验、回归的闭环 | 记忆候选有来源与生命周期，不能替代当前事实 |

第一版感知只选“未戴安全帽”视频事件与“可燃气体浓度异常”传感器事件，均为模拟。后期少量离线图片实验比较结构化基线；无需真实摄像机。半年后期最多用一个小型受限空间任务验证资产复用，不建设第二套业务系统。

安全管理人员保留复核与决定权；Agent 不自动批准、不替代法定审批、不认定责任、不关闭/压制/降级告警、不生成实时控制指令。租户与用户来自可信接入上下文。只用明确标注的合成记录和示例制度；这是个人实践，不宣称企业上线、规模或生产 SLA。

不建设完整电子审批、通用管理后台、生产调度、应急指挥、IoT 管理、视觉训练或通用 Agent 平台。Python/LangGraph 是 Agent 主体，Java 以后提供少数业务 API，不继承旧项目的 Java 唯一权威或旧 Phase/签核机制。
