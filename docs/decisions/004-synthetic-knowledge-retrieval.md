# ADR004：版本化示例知识与本地向量检索

2026-09-20，采用于P2-WP03。目的为可追溯示例依据，不能充当真实企业制度或批准。

沿用项目PG17.11，扩展pgvector0.8.6。当前Windows无管理员/C++/Docker/WSL；官方源码编译路径不可直接执行，conda-forge当前Windows包只匹配PG16，故未硬装不兼容包。采用明确非官方的社区PG17构建，固定发布URL/大小/SHA256，仅复制本项目用户目录中的白名单扩展文件，验证数据库身份及真实SQL余弦排序。不是上游官方二进制，不升级系统PG10。

中文编码采用FastEmbed+本地BGE-small-zh-v1.5/512维，公共模型只下载到.runtime，禁用隐式HF令牌及遥测。首次生成文件摘要manifest，后续只加载本地并拒绝摘要变化；依赖由uv.lock固定。单元测试可用显式假向量，但真实检索评测必须用神经编码，不能降级成随机或常量向量冒称语义能力。

每篇合成文档包含版本、来源、有效期和读者；tenant与owner从可信模拟入口注入。paragraph按最多360字符确定性切分，chunk_id由文档/版本/序号/内容摘要产生。SQL003记录所有版本与片段，只有current且未撤回、授权用户可读、时效有效、编码器匹配的版本进入检索。摄取单文档原子提交，版本替换和片段写入同事务；同版本不同内容拒绝，撤回后不能靠升版静默恢复。批量CLI是多次文档级事务，不宣称整批原子。

小语料采用pgvector精确余弦检索，未引入HNSW或声称规模性能。默认vector；hybrid对候选加中文双字词项重排。已见集对照没有检索收益，继续保留简单默认。回答先为单主题首条摘录，其余候选供人工复核；引用原文存在不代表相关或足够，复合问题/生成摘要后续另验。知识文本只作数据，不提供权限或执行指令。

查询使用一个材料无关的知识入口，暂不改变P1状态；与模型生成/材料综合证据及平台追踪的整合在后续P2工作包进行。异步查询看到的是语句快照，不保证输出后版本永不撤回；高影响动作仍需人工复核最新来源。
