# ADR001：LangGraph 状态边界与内存起步

- 日期：2026-09-17
- 状态：本工作包采用；依据用户指定的 LangGraph 外层与先运行、后持久化顺序。

LangGraph 是工作流状态转换与 checkpoint 的权威。AI 分析器只能返回问题候选，应用代码验证后更新分析状态；用户字段经白名单与版本检查后合并。tenant/user 属于可信入口的归属索引，不能由模型写入，不借框架 thread_id 替代授权。

先用 InMemorySaver 观察节点、条件边和 interrupt/resume，再于 WP02 接官方 PostgreSQL checkpointer。相比立即建 DB，该选择减少首轮排错面；相比 SQLite 过渡，少一次存储迁移。代价是退出即丢失任务，不能宣称跨进程恢复。WP02 必须同时持久化归属索引和图 checkpoint，明确事务/并发/重复恢复风险，不能只更换 saver 就声称完成恢复。

分析节点与等待补充节点分离，避免 resume 重入导致无关的模型请求重复。JSONL 只是观测数据，不参与恢复。当前本地合成演示的 trace 文件失败显示缺口但不阻断材料流程；未来高影响动作的审计策略需独立设计，本决定不授权任何业务写入。
