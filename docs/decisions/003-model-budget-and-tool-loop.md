# ADR003：有界工具循环与跨任务请求预占

日期：2026-09-20。采用，P2-WP02；工程与真实实验结果见该包handoff。

两个事实工具继续由宿主代码执行，模型只生成动作候选。新的核验入口读取有归属的材料快照，默认最多3个模型回合、4次工具动作、75秒总时限。工具白名单、Pydantic参数、业务引用范围和WP01对象授权逐层生效；非法动作形成拒绝观察，不能写材料或修改租户。最终摘要必须引用两个工具已产生的观察，仍标记为未验证候选；引用存在不等于摘要语义正确。

模型协议沿用固定DeepSeek端点及deepseek-flash、非思考模式、1024输出token、20秒请求时限、无重试。请求体上限32KiB，响应体上限64KiB；仅保留动作、候选摘要、来源与用量，不保存隐藏推理。默认scripted模式是明确替身，不能宣称模型决策效果。

用户“长期授权你全力推进”后，采用此前已告知的保守执行上限：每包10次、新授权后项目累计100次，失败也占用。这不是用户指定金额预算；P1历史三次/1184token单独保留。既定供应商/模型不扩价位，不能通过新进程、子Agent或新阶段重置累计数。

选择既有项目PostgreSQL作为唯一生产账本，而不是进程计数或第二个JSON账本：`model_budget_authorizations`固定授权及上限，`model_budget_attempts`保存每次预占。授权ID为`20260920-long-term-v1`，CLI不提供改ID/重置选项。预占事务锁住授权行，计数所有状态后插入；事务提交后才允许HTTP发送。每次请求都是新attempt，finish仅可同值幂等，不允许覆盖完成记录。P1材料入口也接账本，保留原每实例3次更小上限。

硬退出、取消或无法判断供应商是否处理时保留reserved，消耗额度，用量未知记null，不能退款后重试假装未发生。共享账本不可用则不发请求；完成记录写失败时也不退款。预算快照属于辅助读取，失败不能吞掉已完成事实证据。总循环截止补录已知但未完成的attempt，避免报告0请求；账本仍为累计权威。

这只是应用级请求次数限制，不是供应商账单、金额限额或模型调用exactly-once；有数据库管理权限者可以篡改数据。数据库还原到旧备份可能回退计数，今后若还原必须先核对已归档快照/供应商使用记录，不能直接恢复模型实验。测试只用随机test授权ID，不消耗生产授权。

[官方Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)与[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)于本日核对，使用function参数Schema、assistant tool_calls及tool_call_id观察反馈；应用仍须独立验证模型输出。
