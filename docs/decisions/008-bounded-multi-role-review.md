# ADR008：受控并行与两职责模型复核

2026-09-21，P4-WP01/02。事实/知识是确定性只读分支，风险与证据复核是同一供应商模型的两次独立上下文调用，协调器为固定宿主代码；不称为多个模型供应商或自主团队。Graph/PG写连接边界保持ADR002，子角色没有业务写入、批准或报警控制能力。

采集宿主授权材料后冻结revision/run/as-of/身份，固定给事实2次、知识1次工具权限。各自仅获得必要参数；工具、KnowledgeStore、MemoryStore使用时钟副本。超时/取消保留先完成的证据，迟到结果不进入汇合，来源冲突保存拒绝证据并标未知。工具+Memory默认10秒，最终只读材料检查另限2秒；合作式取消不能强杀任意阻塞扩展，不声称端到端SLA。

风险候选沿用P3 context-v2与ReviewCandidate。复核上下文只含风险实际看见的观察/知识、问题、材料版本标识、逐条候选，不传偏好/历史/材料正文。复核逐claim给supported/unsupported/uncertain及来源，宿主只验证引用/完整性，不把模型评价当事实金标。最小上下文会失去材料映射与材料说明的判断依据，已在真实实验暴露；P6再验证更细证据类型。

父最多两模型step、45秒，取消/失败保留已有候选。每个HTTP请求仍由唯一PG账本先预占，子run_id关联parent:risk/evidence；实例counter不是累计权威。DeepSeekReviewModel默认保留P3-WP03，P4明确使用可信P4-WP02，综合报告不得与网关包号不一致。未来改变包号需可信入口与验证，不从模型/材料获取。

协调结果只为待人工复核、有异议或复核不可用；绝不投票批准、不自动改写风险候选。单/双角色真实已见3任务9请求，双角色加95%token和约74%模型阶段延迟，发现两项异议也保留位置映射漏检与离题引用。[完整证据](../phases/phase-04-multi-agent/evidence/wp02/live-report.md)。没有泛化质量或个人掌握结论。
