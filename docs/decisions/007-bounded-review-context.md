# ADR007：有界上下文与单Agent综合证据基线

2026-09-21，P3-WP02/03。保留P2模型自主选工具循环，新增固定三工具采集＋一次模型综合的可对照入口。两者决策机制不同，不能混称自主规划。PG材料归属先于工具/记忆/凭据；采集中材料变化拒绝混合版本，CLI返回后再次核对材料是否仍一致。

context-v2必需部分包括固定边界、版本化业务指引、当前材料/知识问题、所有观察的事实/未知/错误与来源元数据。可选部分依次为有效知识原文、有效枚举偏好、历史。精确限制序列化messages UTF-8字节（最大24000），为网关32KiB完整请求留空间；不是token预算估计。必需部分超限拒绝模型请求，裁剪有id/reason/item_bytes。只接受本用户active且有效、适用的枚举偏好；重复键冲突全剔除。偏好不隐藏未知，也不授予工具权力。

业务指引`hot-work-review-v1.md`由可信代码固定选择并记录版本/摘要；它是Prompt资产，不是可执行插件，也不是权限来源。材料/知识/反馈中出现的指令仅作数据；综合器没有工具执行或批准接口。所有记录仅SYNTHETIC，身份是本地模拟。上下文是采集时快照，不承诺生成过程中实时撤回或强一致事实；高影响操作始终需要人工核对最新来源。

综合输出是逐条claim、observation引用、知识原文引用、完整未知清单及两项呈现字段。只允许引用模型实际看见的片段，裁掉或伪造quote拒绝；必须覆盖观察与未知。每条主张至少带一个来源，输出仍是unverified_candidate，结构合法不证明语义支持。原始候选中不受支持的结构保存在rejected_candidate，隐藏推理和原HTTP响应不保存；trace仅存元数据，完整合成上下文留在显式实验工件。

实验固定P3-WP03，不从材料/偏好推导预算归属。调用前使用唯一PG预占；每个不同任务实例最多3请求，三个任务共9请求，始终共用项目/包上限，失败/未知不退款。run_id在实验调用前保存，按本实验run集合归属增量，其他任务并发新增另列。HTTP/Schema成功与应用候选接受分开统计。

已见三任务消融没有证明记忆质量增益。有记忆比无记忆多755 token，接受率同为2/3；去知识原文少token但丢可引用依据。引用结构仍放过不受支持的上下文说明，材料边界说明因缺少材料引用类型被整体拒绝。保留这些不足，P6再设计细化证据类型/逐主张评测；不为本阶段漂亮结果追加重复请求。详见[真实报告](../phases/phase-03-memory-context/evidence/wp03/live-report.md)。
