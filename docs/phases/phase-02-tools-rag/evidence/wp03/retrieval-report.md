2026-09-20。9篇作者自拟SYNTHETIC示例制度，撤回/未来/过期各1篇排除；8个作者已见单主题开发问题（7个有支持文档、1个无依据问题）。没有独立holdout或专家标签，不是企业制度或生产准确率。

环境：项目PG17.11+pgvector0.8.6（[安装证据](pgvector-setup.json)，明确非官方社区Windows构建、固定发布资产SHA256）；fastembed0.8.0/本地CPU BAAI/bge-small-zh-v1.5，512维，文件摘要[固定](embedding-setup.json)。向量是真实本地神经编码，查询是真实PG余弦距离，不把单元测试的unit-double-512当语义实验。无供应商推理API请求，新授权账本仍6/100。

## 检索与回答选择分开

简单向量检索对比同候选内混合重排（0.75×余弦相似度+0.25×中文双字词项重合），top_k=3、最低相似度0.45。没有改变问题、语料或编码器去美化结果。

| 版本与策略 | recall@3 / MRR（7题） | 回答支持比例（7题宏平均） | 无/有依据判断（8题） |
|---|---|---|---|
| [v1向量](retrieval-v1.json) | 1.0 / 1.0 | 0.4524 | 8/8 |
| v1混合 | 1.0 / 1.0 | 0.4524 | 8/8 |
| [v2向量](retrieval-v2.json) | 1.0 / 1.0 | 1.0 | 8/8 |
| v2混合 | 1.0 / 1.0 | 1.0 | 8/8 |

v1的问题是把所有检索候选都当成回答摘录，其中部分候选没有回答本题。v2只把首条片段放入单主题摘录式回答，其余候选保留供人工复核。**提升来自回答选择，不是混合检索提升**；向量与混合在本集均无命中收益，保留这一无改善结果，不宣称混合一定更好。首条选择针对已见、单支持文档的本集，不能外推到复合问题或未见问题。

回答支持比例按每条回答引用是否属于该问题的supporting_doc_ids计算；当前每篇恰好一个片段，因此文档级gold适用于本集。原文保真度另检查claim是否与所引用片段原文相同，不把“逐字摘录”当成“能回答问题”。这是摘录式证据，不是LLM生成回答质量评测，也不等于独立语义Judge。

旧v1把空答案的quote_fidelity用all([])记为true，原始报告保留。新增[红测](answer-selection-red.xml)后，v2空答案记null，明确7个有回答案例作为保真度分母，7/7；不能将旧8/8当成8个真实摘录均通过。数据/语料摘要在v1/v2一致；16次查询均未返回撤回/未来/过期文档。

v2向量/混合本机平均查询时间约116.49/106.79ms（含本地问题编码与数据库），样本小且顺序运行，不构成性能优劣结论或SLA。混合方法没有足够证据成为优于向量的默认值，默认仍是vector。
