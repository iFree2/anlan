# WP01独立审查与修复

2026-09-20，独立只读审查覆盖tools合同/查询、facts入口、CLI分流、合成数据与对应测试。

发现1项P2问题：仅依赖asyncio.wait_for不能抢占事件循环上的同步解析。审查者以默认reader读取20,001条唯一合法区域记录（约4.58MB），500ms预算下1749.21ms后仍返回ok。主代理新增non_yielding与oversized回归，二者先失败，保留[deadline-red.xml](deadline-red.xml)，没有修改断言迁就结果。

修复：默认文件读取及解析在线程执行；来源文件上限256KiB；发布前检查单调时钟，超过预算丢弃成功结果。独立审查再次运行大数据用例，得到error/data_error、facts=null；主代理工具/入口28项通过，见[tools-reviewed.xml](tools-reviewed.xml)。无其他确认的实质问题。

限制：Python线程不能强制终止阻塞文件I/O，当前保证有界来源及不发布迟到事实，不声称可以强制回收任意底层线程。审查者运行回归期间遇到新增红测，原26项通过、新2项失败；最终修复后的全量回归由主代理单独记录，不能把审查中的失败改写为通过。
