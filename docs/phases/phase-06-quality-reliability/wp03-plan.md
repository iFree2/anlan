# P6-WP03：有限Judge校准和单/双职责复测

Goal：把复核器与可核对的合成标签做有限校准，并复测单/双职责和移除复核的成本/结果变化。沿用持续授权，先冻结、离线验证，再最小真实实验。

## 范围与预算

新包P6-WP03用于独立的文本证据Judge校准/单多职责复测，不用于追加同一感知修复；感知仍归P5-WP02=4/10。当前生产累计34/100。预注册最多8请求：两个合成证据包各一次Judge（2），两个合成任务各单模型1次+风险/复核2次（6）。失败占数、无重试，每个网关实例max_requests=1；1024输出token、20秒、固定deepseek-flash及端点。先完整核对即时账本剩余>=8，否则仅停止依赖调用。

复用现有ReviewCandidate/EvidenceReview、上下文和multi_review；只允许可信宿主参数白名单新增P6-WP03，旧CLI/P3/P4默认不变，不接受模型/材料传包号。输出仍待人工。模型结果失败也保存，未调用步骤不编造用量。

## 冻结与评分

两个Judge包各3条主张，明确supported=可由可见证据支持、unsupported=与证据冲突、uncertain=可见证据不足。2支持/2冲突/2不足，标签由AI按简单枚举事实预先定义、可人工核对；非独立人类金标，不自评当真。标签文件不进入模型上下文，记录输入SHA和混淆矩阵、每类错误、覆盖/拒绝与未知。

两个单/双职责任务是新造但开发者已见的合成数据，不借合同留出冒充模型留出。输入去掉测量耗时，两路同上下文；单路与双路风险独立生成，不能把接受率差异归因于复核修正。复核不改原候选。额外消融在同一双路risk上移除audit，只对协调输出做离线比较，零额外模型请求；明确这是固定候选的录制消融。
