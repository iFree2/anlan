# P10 企业动态 MCP 接入验收

状态：待实施。以下均为后续验收项，不是当前已具备能力。计划见 [开发计划](plan.md)。

## 三个业务场景

- [ ] 设备查询覆盖台账、检验有效期、未关闭故障；未知、过期和查询失败分别呈现。
- [ ] 承包商人员核查覆盖承包商资质、人员培训、进场授权；不同证据不互相替代。
- [ ] 作业票查询覆盖票据、区域、时间窗口和交叉作业候选；区域邻接和编号映射有企业提供的依据。
- [ ] 列表分页、结果完整性和实际覆盖范围明确；未取全或故障不被解释为“没有风险/故障/交叉作业”。

## 注册与企业接入规范

- [ ] 三类能力有版本化输入/输出 Schema、错误语义、状态映射、对象标识、来源和时效规范。
- [ ] 企业注册服务后可通过真实 SDK 完成初始化、工具发现及调用，覆盖受控 stdio 和受信远程 HTTP。
- [ ] 注册、发现、合同验证、启用、刷新和禁用有独立状态及诊断，普通业务身份不能管理服务。
- [ ] 协议连通与业务合同通过分别记录；工具自述和只读标记不代替实际授权及合同验证。
- [ ] 提供三类参考 MCP、合成数据、配置示例、合同测试及企业接入指南。
- [ ] 工具命名不强制企业一致；同能力不同工具名可通过绑定接入，工具别名无碰撞且能还原服务及原名称。
- [ ] 至少一次替换设备 MCP 的演示仅修改配置与外部服务，安澜核心源码不变，结果仍通过相同能力合同。
- [ ] 新增工具或 Schema 变化先验证再发布，配置不执行任意代码，凭据引用不泄露凭据正文。

## 厂区识别与同类服务选择

- [ ] “1工厂”等称呼按当前企业确认的别名解析；不同企业同名厂区不混用。
- [ ] 无厂区时仅使用明确配置的可信默认厂区；未知或歧义称呼先澄清。
- [ ] “一厂旧系统、二厂新系统”按授权对象和来源配置调用；记录选择原因。
- [ ] 同厂区两个作业票 MCP 明确主来源、历史分界、能力补充或双源核对关系；配置冲突不静默择源。
- [ ] 跨系统编号映射明确，跨历史分界查询标明各源覆盖；双源差异分别保留。
- [ ] 备用来源只有在授权、范围与时效满足要求时使用，故障降级在结果中可见。
- [ ] 单次查询固定目录和路由版本；禁用立即阻止新分发并拒绝迟到结果。

## 动态模型调用与证据

- [ ] 模型按任务获取相关且已授权的工具，目录与执行权限一致；无需执行全部已注册工具。
- [ ] 模型意图/对象抽取与宿主授权/选源校验分开，企业身份和对象范围不能被模型参数或工具内容改写。
- [ ] 三场景输出满足动态证据合同，包含来源、对象、时点、完整性及宿主调用元数据；不伪造缺失字段。
- [ ] 超时、取消、无效 Schema、断连、部分失败和工具结果中的恶意指令有明确案例及结果。
- [ ] 工具预算、父任务时限、上下文上限及模型预占账本共同生效，不产生无限循环或隐式付费重试。
- [ ] 追踪能回溯服务、工具、配置/合同/路由版本、来源选择原因及错误，凭据不进入模型或日志。
- [ ] 协议替身、真实 SDK、真实模型和真实企业系统的证据分开报告；没有真实模型结果时不宣称自主选择质量通过。
- [ ] 原固定 Java/MCP、材料状态、身份隔离、只读工具及预算的受影响回归通过；尚未运行项保留状态。

## 阶段交接

- [ ] 状态、接入指南、能力矩阵和交接记录已更新，错误选源及失败案例保留。
- [ ] 不将合成演示升级为真实企业上线证明，不开放审批、设备或报警控制。
