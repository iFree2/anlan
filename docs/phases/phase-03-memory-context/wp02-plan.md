# P3-WP02：受控上下文组装计划

延续长期授权，首包验证归档后实施。本包重点是可解释的上下文筛选与预算；不重写P2模型工具循环。采用独立综合证据入口：同一Graph快照→两个既有事实工具→既有知识工具→有效偏好→上下文→单次结构化综合候选。固定采集与单模型综合明确区分于P2模型自主选工具循环；后续单/多对照必须沿用同一采集与评分口径。

设计取舍：在已有tool-call历史里直接剪片段会破坏协议配对并混淆未见引用；因此新上下文模块消费完整受控观察，不修改P2历史。预算用序列化messages的UTF-8字节精确计数（不是token），最多24000字节，为固定网关32KiB请求留出空间；实际token仅来自usage。必保留系统边界、当前材料、事实/知识的状态与来源元数据、所有未知/错误。必需部分超限直接拒绝，不请求模型；可选有效知识原文、有效相关枚举偏好按优先级加入，历史最低。每次裁剪记录类别/id/reason/bytes，不记正文、秘密或隐藏推理。

偏好只能改变详略/顺序，不覆盖当前事实和未知、不授予权限。组装再次验证归属、状态、时效、白名单及适用任务类型。知识由已校验的本轮工具返回；无/有记忆、无知识原文、小预算和恶意候选均使用同一开发样本比较。输出验证仅接受本次实际入上下文的引用，不能引用被裁掉的片段。
