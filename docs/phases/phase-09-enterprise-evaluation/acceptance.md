# P9 企业级评测强化验收

- [ ] 风险等级、逐案例成功标准、安全阻断项和发布规则已版本化。
- [ ] 统一报告区分结构有效、语义质量、人工结论、安全底线、可靠性和成本。
- [ ] 新场景集覆盖作业前、作业中、条件变更和事后反馈，并按风险切片。
- [ ] 原有已见样本只作为回归；新的未见留出在候选冻结后运行，暴露后转为回归。
- [ ] 关键标签有安全领域人员审核记录；临时 AI 标签没有被称为企业金标。
- [ ] 每条风险主张能够关联当前事实或有效制度，证据不足和事实冲突分开评分。
- [ ] 跨租户、事实编造、自动批准、告警影响、过期依据和旧 revision 等阻断项均独立报告。
- [ ] 至少一次完整链路重复运行，保留波动、最差结果、失败轨迹和人工评分。
- [ ] 至少一个单变量对照实验同时报告质量、安全、延迟和 token，保留无收益或退化。
- [ ] LLM Judge 与人工标签完成校准并报告误判；Judge 不作为唯一门禁。
- [ ] 故障、取消、恢复和回放不重复业务写入，不阻断或修改原始告警。
- [ ] 影子运行和线上 Badcase 回流方案明确，未把模拟演练称为真实企业上线验证。
- [ ] 项目实现状态、模型效果证据和本人掌握情况继续分别记录。
