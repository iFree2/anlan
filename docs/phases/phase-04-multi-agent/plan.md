首包只复用现有事实工具与知识工具，分别消费最小对象引用或显式知识问题，结果由宿主校验后汇合。没有必要就不在分支内追加模型；固定职责任务只能叫确定性分支，不能冒称多个模型自治Agent。沿用P3材料快照和context/synthesize，先保持相同输出合同和合成数据，避免同时改采集和评分。

实现前读适用AGENTS、product/status/roadmap、P3handoff、ADR002—007，查看Git与原始P3 Gate/模型失败。设计每分支允许输入输出/工具、父子总预算、deadline、取消和部分失败语义；首包本地真工具，不需模型凭据或新依赖。并发任务不能共享LangGraph写连接或直接写公共状态；Graph恢复边界保持ADR002。

P3基线为3任务×3上下文策略已见集；接受6/9不是泛化质量。P4应报告任务效果、主张支持、未知覆盖、延迟/token、增加编排复杂度；保留无收益或退化。原P2混合无增益、P3有记忆额外token且未增接受率必须保留。
