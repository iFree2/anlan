## AI逐条复核（不是本人实践或独立人工金标）

- current单/双：资质active、区域restricted及监护要求有对应依据，额外材料准备条款偏离监护主题，严格目标来源指标两路均false。复核4条全supported，却称“A区1号台”未超观察范围；它的最小上下文只有对象ID、没有材料位置映射，不能独立确认此名称。这是复核过度自信与最小上下文损失，不能以4/4支持证明质量。
- expired单：保留两项expired/unknown；“仅返回检索状态与示例依据”仍有含混上下文说明，知识原文实际可见。部分区域知识引用主题不直接对应过期，但观察o2支持过期事实。双角色risk第4条把当前事实未知扩成“材料不足”，复核给uncertain，正确指出观察未证明材料不足；其余3条supported。原候选未被自动修正，异议留给人工。
- no-knowledge单：事实与知识未知均正确；材料注入不构成授权的说明本身合理，但无引用，当前合同缺材料引用类型，整体unsupported_output。原候选与unknown清单保留，不应称模型漏报未知。
