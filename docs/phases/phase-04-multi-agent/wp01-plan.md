# P4-WP01：受控双分支采集

2026-09-21。依持续授权直接实施，同目录；不读取模型凭据、不发送模型请求。采用 writing-plans/TDD/验证工作流，工程事实与个人掌握分开。

## 设计与取舍

保留 P3 串行基线；新增宿主编排的确定性 facts/knowledge 两职责分支。比较过直接共享 Graph 并行（会扩大 ADR002 写连接边界）和每分支模型自治（本包无必要付费且改变变量）；选只读独立能力与固定 fan-out/fan-in。分支没有 service、memory、材料正文、账本或彼此输出；只获得可信身份副本、父子 ID、材料 revision/run、固定 as-of、期限及必要参数。独立分支不代表多模型自治或安全沙箱。

父级在授权后一次冻结材料/身份/时点，规范顺序预分配最多3工具动作（事实2，知识1），失败、取消、超时不退款，不因并发竞争改变预算分配。每次执行前检查预算/单调deadline，完成后检查是否迟到。按 worker/area/knowledge 固定顺序汇合，未知占位保留完整三观察合同；部分成功不丢失。外部任务取消传播并回收子任务；显式取消事件返回已成功证据加未知。线程内只读 I/O 无法强杀，但迟到结果不发布，也无共享状态写入。

宿主验证工具、对象、时点、来源；同资源版本/hash冲突、同文档多版本或同chunk不同原文明确冲突，不能投票择一。结束再次从 service 读取材料并比较整个快照；不一致抛 InvalidTransition。Memory 在父级有界读取，分支不读偏好。原 context-v2/synthesize 合同及 P3评分保留；P4首包使用替身综合，报告清晰记录归属与采集模式。
